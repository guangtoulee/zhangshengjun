# 张圣君官网 40 秒主片制作说明

## 剪辑决定

八段生成视频分别合成为横版与竖版两条 40.216 秒主片。四个章节保留生成时设计的叙事硬切，不额外叠化：

1. `00:00.000` 漆裂成山，法主显现
2. `00:10.054` 法索擦镜，食桃悟道
3. `00:20.108` 雷环化剑，剑锋入水
4. `00:30.162` 水纹成田，万香归宗
5. `00:40.216` 回到黑漆与朱砂裂隙，可循环衔接第一幕

## 输出文件

- `public/zhangshengjun/video/hero-cinematic-wide.mp4`：1280×720，30fps，H.264 High，AAC 48kHz 双声道。
- `public/zhangshengjun/video/hero-cinematic-mobile.mp4`：720×1280，30fps，H.264 High，AAC 48kHz 双声道。

两个版本使用同一条整理后的横版声场，避免横竖设备听到两套不同声音。三个声音接缝采用 0.12 秒交叉过渡，统一至约 -18 LUFS，并在结尾渐弱以适应循环。

## 网站行为

- 首屏按照设备选择横版或竖版文件，默认静音、自动播放、循环。
- 四幕标题根据视频时间自动同步，点击缩略图或前后按钮可跳转到对应章节。
- 首屏滚出视口、打开完整播放器或页面要求减少动态效果时，背景主片暂停。
- 用户开启省流量模式时不请求视频，保留同源静态主视觉。
- “法主视界”按钮打开完整播放器，用户可主动开启声音、拖动进度或全屏观看。
- 静态图继续承担首帧、弱网、播放失败和无动态模式的降级显示。

## 编码策略

- 画面：`libx264`，CRF 25，最高码率约 2.8 Mbps，`yuv420p`，网页兼容优先。
- 关键帧：在约 10.054 秒的章节间隔强制关键帧，方便网页章节跳转。
- 封装：启用 MP4 Fast Start，使浏览器无需下载完整文件即可开始播放。
- 字幕：主片无对白、无烧录文字，因此不配置 SRT；网站标题由 HTML 实时覆盖。
