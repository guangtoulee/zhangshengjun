# 张圣君文化官网平台化升级路线

更新日期：2026-07-30

## 1. 当前结论

2026 年 7 月 30 日已完成第一阶段 SEO 与内容架构升级：

- canonical、Open Graph、robots 和 sitemap 已统一到 `https://www.zhangshengjun.org`。
- 新增 Organization、WebSite、CollectionPage、BreadcrumbList 与 VideoObject 结构化数据。
- 简体、繁体与英文均新增 `/legend`、`/lushan`、`/news`、`/videos`、`/shop` 五类独立入口。
- 首页主导航已由页内锚点升级为独立内容页面内链。
- 影音页已根据设备选择横版或竖版主题影片。
- 文创页暂为公开研发目录，不显示价格、不接购物车与支付。

下一阶段的核心问题不再是“有没有独立页面”，而是继续补充主题深度、真实活动、来源引用、独立文章与外部权威链接。

仍需处理的事项：

1. 添加 Google Search Console 与 Bing Webmaster 的 DNS 验证并提交 sitemap。
2. 将五个栏目继续拆分为可长期积累权重的文章、地点、视频与史料详情页。
3. 为内容补充署名、审核者、参考文献与真实更新时间。
4. 全站主要首页仍集中在一个大型客户端组件中，后续需要逐步模块化。
5. 46MB 媒体资源仍直接进入 Git 仓库；未来系统视频和数字下载应迁入对象存储。

## 2. 推荐技术架构

### 前台与运行平台

- 保留 Next.js App Router。
- 当前继续使用 Vercel 生产部署，Cloudflare 负责域名注册、DNS 与基础网络能力。
- 不立即迁移托管平台；当自然流量、媒体容量或商业功能增长后，再在 Vercel Pro、Cloudflare Workers 或境内云之间按实际成本选择。
- 若后续选择 Cloudflare Workers，使用 OpenNext 适配现有 Next.js，并先在预览域名验收后再切换 DNS。
- 将首页拆成服务端内容区块与少量客户端交互组件。
- 独立文章、视频、产品页面采用服务端渲染或增量静态生成。

Cloudflare 作为后续候选的重要原因：

- Vercel Hobby 只允许非商业个人用途。上线商品销售或处理付款后，需要 Vercel Pro 或其他商业托管方案。
- Cloudflare 已经管理当前域名。
- Payload 官方支持 Cloudflare Workers、D1 与 R2。
- Next.js App Router、SSR、SSG、ISR 和 Server Actions 可通过 OpenNext 部署到 Workers。
- 初期可使用 Workers 免费额度；需要更稳定的后台运行时，Workers Paid 最低月费通常低于 Vercel Pro。

### 中国大陆访问

- Cloudflare 普通全球网络与 Vercel 均不能保证中国大陆各运营商、各地区始终低延迟。
- 真正使用 Cloudflare 中国网络需要企业合同、China Network 套餐与有效 ICP 备案；Cloudflare Pages 本身不在中国大陆境内提供节点。
- 当前优化原则是自托管字体与媒体、减少第三方脚本、压缩图片视频、避免加载被阻断的海外 API。
- 当大陆自然流量形成后，优先评估 ICP 备案与腾讯云、阿里云、华为云或 EdgeOne 境内部署/镜像；预算充足时再评估 Cloudflare China Enterprise。

### 后台

采用 Payload CMS，直接嵌入当前 Next.js 项目：

- 后台入口：`/admin`
- 管理员与编辑账号
- 三语字段
- 草稿、版本记录、预览、定时发布
- 图片与文件媒体库
- 页面模块自由排序
- REST/GraphQL/Local API
- 后续可继续接入购物车、订单和支付

不建议自行从零开发 CRUD 后台。身份验证、权限、草稿、版本、媒体引用和定时发布都属于容易留下安全与数据问题的基础设施。

### 数据库与媒体

- 数据库：Cloudflare D1，使用 Payload 官方 `@payloadcms/db-d1-sqlite` 适配器。
- 图片、海报、PDF、音频、视频、数字商品源文件：Cloudflare R2。
- 公共媒体域名：`media.zhangshengjun.org`。
- 私有数字下载：R2 私有 Bucket + 有时效的签名下载链接。
- 长视频初期使用 R2 MP4；数量和播放量增加后切换 Cloudflare Stream。

### 安全

- 后台只允许管理员与编辑登录。
- 管理员启用强密码和双重认证。
- 表单使用 Cloudflare Turnstile。
- 商品下载不暴露源文件 URL。
- 订单、下载权限和后台 API 均有服务端鉴权与速率限制。

## 3. 后台内容模型

### 核心内容

`Pages`

- 页面标题、Slug、摘要
- 三语正文
- 自由组合区块
- SEO 标题、描述、分享图
- canonical、索引开关
- 发布时间、更新时间

`Articles`

- 新闻、研究、非遗、两岸交流、母殿动态
- 作者、审核者、来源与参考文献
- 主题标签、相关文章
- 三语状态可分别发布

`Topics`

- 张圣君
- 闾山派
- 亦道亦佛
- 方壶岩
- 造像艺术
- 游田与农业保护神
- 两岸及海外信仰

`Sources`

- 古籍、论文、地方志、新闻来源
- 作者、年代、出版信息、原文链接或附件
- 可被文章和视频重复引用

`Events`

- 庆诞、进香、交流活动、展览
- 时间、地点、主办方、报名状态

### 视频

`VideoSeries`

- 系列名称、介绍、封面、排序

`Videos`

- 标题、Slug、海报、视频地址
- 时长、发布日期、主讲人
- 章节时间点
- 完整文字稿
- 引用来源
- 相关文章与相关视频
- 横版、竖版和短视频版本

### 商城

`Products`

- 实体文创
- 数字图片/电子屏保
- 视频屏保
- 数字艺术作品
- 每日黄历或订阅内容
- 文化主题电子符箓

每个商品包括：

- 商品类型、标题、Slug、图库
- 三语介绍
- 价格、币种、状态、库存
- 数字文件、授权范围、版本
- 是否允许预览、下载次数与有效期
- SEO 与 Product 结构化数据

`Orders`、`Customers`、`Downloads`

- 第二阶段启用
- 订单状态、支付状态、退款
- 数字商品授权与下载记录
- 实体商品物流信息

“电子符箓”“每日黄历”应明确定位为文化创意与数字艺术内容，不宣传医疗、投资、改运等可验证功效。

### 全局配置

`SiteSettings`

- 导航、页脚、Logo、社交账号
- 联系方式、地址、版权
- 默认 SEO、统计代码

`Redirects`

- 旧 URL 到新 URL 的永久跳转
- 内容改名时自动维护 SEO

## 5. 视频中心设计

建议首批建立 4 个系列：

1. 《张圣君传奇》
2. 《闾山派入门》
3. 《法相与法器》
4. 《信俗在现场》

每个视频必须拥有独立观看页，而不是只在首页弹窗播放。页面包含：

- 可播放视频
- 200 至 400 字摘要
- 完整文字稿
- 分章节时间点
- 引用史料
- 人物、地点与术语链接
- 相关推荐
- `VideoObject` 与章节结构化数据

这既服务用户，也让搜索引擎能理解视频内容。

## 6. 商城实施方式

### 第一阶段：商品目录

- 上线商城首页和商品详情页
- 商品可由后台编辑
- 支持“即将推出”“免费领取”“登记兴趣”
- 暂不接支付，先完成品牌、内容与搜索收录

### 第二阶段：数字商品

- 购物车、支付、订单
- 支付成功后生成签名下载链接
- 控制下载次数和期限
- 记录数字作品授权版本

### 第三阶段：实体商品与订阅

- 库存与物流
- 每日黄历订阅
- 会员内容
- 海内外不同支付与配送策略

支付层采用适配器设计：

- 海外：Stripe
- 中国大陆：待具备合适经营主体后接微信支付/支付宝的合规商户通道
- 不把支付逻辑锁死在单一平台

## 9. 衡量目标

上线后按 30、60、90 天检查：

- Google 已索引有效页面数量
- “张圣君”“法主公”“闾山派”等非品牌/主题词曝光
- 视频搜索曝光和关键时刻展示
- 自然搜索点击与平均排名
- 文章到视频、视频到商城的内部转化
- 商品兴趣登记、免费领取与订单转化

搜索收录与排名没有即时保证。目标是消除技术冲突、建立可信内容实体，并持续发布值得被引用的原创内容。
